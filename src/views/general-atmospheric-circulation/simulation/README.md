# 三维地表图层

从本机“三圈环流-self”项目的 `src/simulation` 迁入：

- `surface-arrows.ts`：球面平面箭头、端点裁剪、交错出现与沿路径运动。
- `geographic-paths.ts`、`model.ts`：同一套季风/洋流经纬度路径、跨日界线插值、季节换向。
- `flow-effects.ts`、`shaders.ts`：气压带羽化边缘、洋流连续流线及脉冲。
- `PressureField.ts`、`pressure-data.ts`、`PressureCenterText.ts`、`contour-labels.ts`：球面气压场、等压线、区域极值定位与贴球文字。
- `seasonal-controls.ts`、`Sunlight.ts`：阶段三使用春分、夏至、秋分、冬至的直射纬度（0°、北纬23°26′、0°、南纬23°26′）；阶段四保留2026年1月、7月15日的参考纬度。纬线不表示整圈同时直射。

`SurfaceClimate.ts` 将参考项目的图层接入现有四阶段页面，不替换原来的单圈/三圈烟流、相机或背景。颜色集中在 `model.palette` 和 `pressure-palette.ts`，图例和图层共用它们。海平面气压填色参照教材采用低压黄橙、高压蓝紫，图例数字直接作为色带分界，不作为各档中心。1月分界为996、1000、1004、1008、1016、1020、1024、1028、1036 hPa，共10个有色区间；7月分界为996、1000、1008、1012、1020、1024、1026 hPa，共8个有色区间，最外两档覆盖低于、超过分界范围的气压值。1月1008–1016 hPa整段为浅米色；7月1008–1012 hPa为浅米色，1012–1020 hPa为浅蓝紫。所有色区统一采用0.60不透明度，不在1012 hPa附近挖出透明区。

等压线默认关闭，手动开启时显示4 hPa主线，七月额外显示资料中实际达到1026 hPa的部分。气压数值标注与线条开关独立，位置取真实气压等值交点；例如7月1004 hPa、1月1012 hPa可作为数值标签，但不因此增加填色分界。月份图例、填色区间和等压线间隔分别定义。

沿用当前页面的 NOAA/NCEP 1981—2010 年1月、7月气候平均资料；文件与参考项目完全相同。这是对真实资料采用教材式分级呈现，并非教材原始数据，区域边界和极值不强行改成教材概化图。气压中心的 H/L 位于相应月份的区域局部极值。气压场切换时的插值仅是视觉过渡，不作为中间月份的数据；过渡期间隐藏等压线数值并淡出旧月份的气压中心文字。

季节或月份切换保留几何体、顶点缓冲区和运动相位，使用参考项目的指数缓动。阶段三的气压带、风带以0°、北移5°、0°、南移5°示意春分、夏至、秋分、冬至的季节变化，与太阳直射纬度分开计算。0°、±30°、±60°主气压带的示意半宽均为5°，夏至赤道低压带范围为0°–10°N，冬至为10°S–0°；这属于教材模型的示意宽度与位移，不是实际气压带的固定尺度。70°以内同幅平移，70°至极点逐渐收敛，极点保持固定，避免截断和越极。阶段四仍只使用1月、7月气候资料，参考气压带保留原有±7.5°季节位移，实际气压场不随示意气压带变形。`seasonal-warp.ts` 对原有环流剖面使用相同纬度变换。暂停只停止气流运动，季节、月份和图层切换仍平滑过渡。

风带与季风共用贴球面的弯曲细尾平面箭头，季风沿完整经纬路线运动。风带、季风和洋流均是教学示意路径，箭头长短与动画速度不代表实测风速或流速。

阶段四7月的南亚两支夏季风从南半球东南信风源头连续向北演示：赤道以南使用信风蓝色，越过赤道后随实际顶点纬度在0°–5°N之间逐渐变为西南季风紫色；该渐变范围是帮助观察的视觉示意，不是实际风向变化的固定纬度界限。一根横跨赤道的长箭头仍保留蓝色的南端，路线在跨赤道后逐渐转向东北。进入7月季风、重新打开季风图层时，箭头依次从南端发出，首次到达前不会直接在北半球生成；后续沿完整路线循环，暂停冻结位置与着色。印度洋局部重合的东南信风箭头在该演示开启时由连续跨赤道路线替代，其他经度的风带及冬季路线保持原样。两个西南季风分支名称分别锚定北半球的阿拉伯海和孟加拉湾路线，并使用短两行标签。

跨赤道低空气流与北半球季风分支的科学依据参见[印度气象局季风常见问题](https://imdpune.gov.in/faq_monsoon.php)及[印度政府新闻局：The Indian Monsoon](https://www.pib.gov.in/PressNoteDetails.aspx?ModuleId=3&NoteId=154892&lang=2&reg=3)。这里的两条曲线用于解释来源、偏转和输送方向，并非逐点实测轨迹，也不表示所有孟加拉湾气流都来自同一条通道。

阶段四1月另显示东北信风向澳大利亚北部的跨赤道过程：北半球源头向西南运动，保持信风蓝色，过赤道后向左偏转、逐渐吹向东南，并在0°–5°S之间变为西北季风紫色。名称“西北季风／澳大利亚北部”锚定南半球目的地路线；1月是该地区的夏季，不标成南半球冬季风。南亚原有的1月东北季风仍沿独立的北半球路线展示，不把全部东北信风改为跨赤道气流。该澳北路线只在1月启用，重新进入该月份或打开季风图层后从北方源头依次发出，循环与暂停规则同上。南半球12月至3月西北季风及其跨赤道来源参见[澳大利亚气象局：低层风场流线图说明](https://www.bom.gov.au/australia/charts/Interpreting_GLW.shtml)。曲线和0°–5°S着色过渡同样是教学示意，不是实测轨迹或固定转向纬度。

`MonsoonDefinition.crossEquatorial` 显式配置目的半球、启用月份和标签纬度，`label` 与 `color` 分别配置短名称和目的地颜色。发射时钟沿用 `advanceMonsoonLaunch` / `monsoonLaunchPhase`，由各条路线自己的 `activeMonth` 控制；以目的地区域判断夏季，不从名称字符串推断。

“风向与受力”使用关于赤道严格镜像的教学对照：两处锚点位于同一105°E经度的7°N、7°S，轨迹分别覆盖5°–9°N/S，以相同相位运动。曲率参考孟加拉湾支流的目的地段，再平移经度、作南北镜像；这两处对照不代表原季风路线的实际地理位置，实际季风路线未改。`illustration='equatorial-mirror'` 明确标记对照类型，`routeId` 仅记录形状参考，`representedMonth` 指明北侧对应7月、南侧对应1月。风向取所显示镜像曲线的球面切线；北半球东北向风的地转偏向力指向右侧（东南），南半球东南向风的地转偏向力指向左侧（东北）。箭头、起点、轨迹与力向量均按当地地表坐标镜像，参见[NOAA：地转偏向效应](https://oceanservice.noaa.gov/education/tutorial_currents/04currents1.html)。水平气压梯度力仅示意朝接收半球低压区的方向，并未从月平均气压场计算瞬时力，未显示摩擦力，也不构成实测力平衡。锚点不随月份或相机选择改变；两处示意随地球旋转，并保留地球背面的遮挡。

## 校验

在本页面目录运行：

```powershell
node --experimental-transform-types --test tests/*.test.mjs
```

测试包括球面贴合、箭头/季风方向、北印度洋洋流换向、跨日界线路径、真实气压极值及等压线数值、切月时缓冲区/相位保留、开关和四阶段三维模式。
