# 《海底地形》3D 课件设计（seafloor-topography）

- 日期：2026-10-23
- 视图：`src/views/seafloor-topography/`，路由 `/seafloor-topography`
- 教材来源：中华中图版《地理》六年级上册（五四学制）第三单元 第一节 海陆分布，印刷 P66 图 3-21「海底地形类型示意」（官方 PDF 第 70 页）

## 1. 背景与已确认决策

课堂用法：教师演示 + 学生探索都要（默认自动巡游，可随时接管）。
内容范围：只做图 3-21 的六类地形；不含 P67 资源文字、人物窗（玛丽·萨普）、图 3-22。
场景表现形式：方案 A「教材同款块状剖面」——斜 45° 立体块、前立面地层剖面，构图与标注位置对照图 3-21；材质光照走写实自然风。
页面骨架：方案 A「底部单行 dock」——无左右面板，控制与播放压成底部一行；说明用场景内浮层卡。
文案口径：四类用教材原文逐字；大洋盆地、岛弧补一句通用定义并标「补充说明·非教材原文」；教材没给的深度数字一律不写。

用户追加的三条硬要求：

1. 3D 还原度要高——分段比例、配色、构图对着图 3-21 还原。
2. 海底地形的纹路要清晰——地形表面的沟脊起伏在近看和投影上都要读得出来。
3. 要能钻到海底近距离查看——相机可以下到水面以下、贴近海床看。

## 2. 场景几何与还原度

一块斜置长方体地块，顶面为地形面，前立面与左侧面为棕褐色地层剖面。顶面沿 X 轴分七段，比例对照图 3-21（x 为 0–1 分数，实现时以教材截图为准微调）：

| 段 | x 范围 | 形态 | 模型深度（夸张单位，水面=0） |
| --- | --- | --- | --- |
| 陆地 | 0–0.16 | 绿色陆面，微起伏 | +1.2 |
| 大陆架 | 0.16–0.30 | 极缓浅滩 | −0.6 |
| 大陆坡 | 0.30–0.42 | 陡降 | −0.6 → −3.0 |
| 岛弧 | 0.42–0.47 | 一列 4–5 个火山锥，锥顶接近或略出水面 | 锥基 −3.0 |
| 海沟 | 0.47–0.53 | 窄 V 形深槽，并在前立面切面上切出同形深槽 | −7.5 |
| 大洋盆地 | 0.53–0.80 | 宽广平缓 | −5.0 |
| 海岭 | 0.80–0.92 | 隆起山脊，脊顶带中央裂谷凹口 | 脊顶 −2.2 |
| 盆尾 | 0.92–1.0 | 回落到盆地深度 | −5.0 |

- 几何程序化生成：一条剖面控制点曲线（上表）+ 横向多倍频噪声起伏，拉伸成地形面；前立面与左侧面由同一剖面闭合生成实体。不引外部模型或贴图文件。
- 上表 x 区间互不重叠，是点击判类、高亮分段、标签锚点、水深尺刻度的唯一区间来源（定义在 `seafloor-data.ts`）。岛弧锥裙与海沟槽缘在几何上允许越界少许，但判类一律按区间。
- 海水：仅覆盖 x>0.16 的区域，顶面之上一块半透明水面平面（水面 y=0），陆地露出。
- 配色对照图 3-21：陆地草绿、大陆架浅青、坡与盆灰蓝、海岭略浅、切面棕褐、水面半透明青。材质用 MeshStandardMaterial + 顶点色渐变，写实自然风（半球光 + 暖顶方向光 + 暗背景雾）。
- 图 3-21 右上角的小船做一个低模点缀放在水面上，位置对照原图。
- 真实深度比（200 m 对 11000 m）无法等比，采用上表的垂直夸张；水深尺标「示意·非等比」。

## 3. 纹路清晰度

- 地形网格细分不低于 256×128 段，保证沟脊有几何而不是靠贴图假装有。
- 每段用不同特征的程序化细节：大陆坡放射状冲沟、大洋盆地低频丘陵、海岭两翼断层阶地 + 脊顶裂谷、海沟光滑 V 槽、岛弧锥体带放射脊。噪声按段混合，段界平滑过渡。
- 一盏低仰度的侧向方向光（掠射光）专用于把微起伏拉出明暗，配合半球光补底。
- 顶点色随坡度/深度轻微变化，增强沟脊可读性。
- 验收标准：默认斜 45° 机位截图上，大陆坡冲沟、海岭裂谷、海沟槽线三者肉眼可辨。

## 4. 下潜近看

- 视角预设三档（option-btn 组）：斜 45°（教材机位，默认）／正视剖面／下潜近看。
- 「下潜近看」：相机动画飞到当前选中地形（未选中时默认海沟）海床上方约 1–2 个单位的低机位，OrbitControls 目标落到该处海床点，minDistance 收紧到可贴近观察。
- 自由轨道任何时候都允许把相机转到水面以下，不做人为限制。
- 水下渲染：水面材质 DoubleSide + 透明，从下方看是一层透光顶棚；相机 y < 0 时切换为水下雾色（深青绿）并提高雾密度，出水自动恢复。
- 地块是实心实体，相机始终在海床面以上，不会穿进地层。

## 5. 标注、选中与说明卡

- 六类地形各一个 HTML 覆盖标签（每帧投影锚点定位，不用 sprite），「标注」switch 控制显隐；锚点位置对照图 3-21 的标注落点。
- 点击地形面：raycast 命中点按 x 区间判类 → 该段高亮（emissive 提亮）+ 打开说明卡。
- 说明卡为场景右上角浮层，可 × 收起；内容 = 名称 + 说明 + 深度行。
- 四类教材原文逐字：
  - 大陆架：大陆架是陆地向海洋的自然延伸部分，坡度比较缓，水深一般在 200 米以内。
  - 大陆坡：大陆坡是大陆架向海洋倾斜的陡坡，水深急剧增至数千米。
  - 海沟：海沟是海洋底部最深的地方，最大水深 1 万多米。
  - 海岭：海岭是狭长绵延的大洋底部高地，一般高出两侧海底 3000 ~ 4000 米。位于大洋中央部分的海岭，也称大洋中脊。
- 两类补充（卡上带「补充说明·非教材原文」小字，不写深度行）：
  - 大洋盆地：大洋底部宽广而相对平坦的凹地，是海底面积最大的部分。
  - 岛弧：呈弧形分布的群岛，常与海沟相伴出现。
- 深度行只写教材给了的：200 米以内／数千米／1 万多米／高出两侧 3000 ~ 4000 米。

## 6. 水深尺

前立面左缘一条垂直刻度条（HTML 覆盖层，随剖面锚点投影）：四个刻度对齐模型中各地形的实际位置，刻度文字用教材口径（200 米以内／数千米／1 万多米／高出两侧 3000 ~ 4000 米），顶部标「示意·非等比」。不做假线性刻度。「水深尺」switch 控制显隐。

## 7. 巡游时间轴

- 7 站：海岸 → 大陆架 → 大陆坡 → 岛弧 → 海沟 → 大洋盆地 → 海岭。progress 0–100 线性映射到 7 段；每站内前 70% 相机 ease 移向该站机位、后 30% 停留；**进入该站时**（段起点）自动高亮该段并自动打开其说明卡，相机在飞行途中卡片已切换（预览式）。
- 播放/暂停、进度 slider、1×/1.5×/2× 速度用模板已有 timeline-dock 控件。
- 用户拖 OrbitControls 或点击地形 → 自动 `isPlaying=false` 交还控制权；再按播放从当前 progress 继续。
- 巡游机位均在水面以上的表层机位；下潜近看是独立视角预设，不参与巡游。

## 8. 控制区（底部单行）

timeline-dock 同一行内，从左到右：播放钮、进度 slider、速度组 ｜ 「标注」switch、「水深尺」switch、视角 option-btn 组（斜 45°／正视剖面／下潜近看）、复位钮（reset-scene-btn）。
复位 = 回到斜 45° 默认机位 + 取消选中 + 收起说明卡 + progress 归 0。
不新增左右面板；`hasLeftPanel`/`hasRightPanel` 保持 false。

## 9. 文件结构与职责

- `index.vue`：模板结构、UI 状态（开关/视角/选中/进度）、巡游调度、raycast 接线、标签与说明卡与水深尺的 DOM 更新。
- `seafloor-data.ts`：六类地形定义（名称、原文/补充、补充标记、深度行、x 区间、锚点）、剖面控制点表、巡游站表、配色常量。纯数据，无 three 依赖。
- `seafloor-geometry.ts`：由剖面控制点 + 分段噪声生成地形面、地块实体（前/左切面）、水面平面的 BufferGeometry；导出分段判类用的 x 区间查询。
- `seafloor-scene.ts`：three 装配——renderer/相机/OrbitControls/光照/雾/材质、机位预设与相机动画、水下雾切换、resize 与 dispose；每帧通过 `callbacks.onOverlay(items)` 回投标签与水深尺刻度的屏幕坐标，并暴露 `pick(clientX, clientY, rect)` 供点击判类。场景模块不直接操作业务 DOM。
- `index.vue` 用 onOverlay 的结果更新标签、水深尺刻度的 DOM 位置，用 pick 接画布点击（带拖拽/点击区分）；DOM 结构与文案全在 index.vue。
- 单元之间只通过 `seafloor-data.ts` 的常量与场景模块的显式方法通信。

## 10. 模板与工程约束

- 复用 `@/hooks/useGeoPanelLayout`，`<main class="workspace">` 用 `v-bind="workspaceAttrs"`；root 用 hook 的 rootRef。
- three 只挂 `scene-host`；canvas 不用 fixed；`state.resizing` 为真时跳过 `renderer.setSize()`；ResizeObserver 在 `draggingSide`/`viewportResizing` 为真时跳过；resize 防抖、尺寸未变跳过、setSize 后补绘一帧。
- 按钮只用公共类：`theme-btn option-btn`（+active）、`theme-btn speed-btn`、`theme-btn reset-scene-btn`、`timeline-icon-btn`；switch 用 `switch-row` + `control-copy`。**例外（已记录）**：底部单行 dock 内的两个 switch 用业务局部类 `.dock-switch`（`switch-row` 是带下边框的整宽面板行，塞进单行 dock 会破版；先例见 threeD-terrain 的 `.dock-switch-item`）。dock 本身加业务修饰类改排布（flex 单行），只改排布不改公共配色/毛玻璃。不重写公共颜色/毛玻璃/滚动条样式。
- 删除模板残留：`aiTemplatePrompt`、`copyTemplatePrompt`、`.stage-placeholder.template-prompt-card` 及相关状态。
- 不引入新依赖（three 已在项目内）。

## 11. 验证

不启动 dev server；在用户已运行的 :5173 上用浏览器截图逐项核对：

1. 默认斜 45° 机位与图 3-21 截图并排对照：七段顺序、比例、配色、小船位置。
2. 纹路：大陆坡冲沟、海岭裂谷、海沟槽线在截图上可辨。
3. 六类点击：高亮 + 说明卡文字与第 5 节逐字一致；大洋盆地/岛弧带「补充说明」小字且无深度行。
4. 下潜近看：相机入水后雾色变化、水面从下方可见、贴近海床不穿模；出水恢复。
5. 巡游：播放走完 7 站，每站高亮与说明卡正确；中途拖轨道会暂停。
6. 水深尺与标注开关显隐正常；标签在旋转/缩放时不跑位、不被裁切。
7. 拖拽面板与缩放窗口不闪不拉伸（resize 规则）。

## 12. 非目标

- 不做图 3-22 全球海底地形、人物窗、P67 资源文字。
- 不做可开关剖切（方案 C）、不做真实等比深度、不做水声/粒子等特效。
- 不做移动端手势专项适配（希沃大屏与桌面浏览器为准）。
