# 地图三要素：A、B 两点方位判读说明

适用课件：`src/views/three-feature-of-map`  
核对日期：2026-10-07

## 1. 先说明参照点和判断规则

本课件回答的是：**以 A 点为参照，B 点位于什么方向？**

- 南北关系根据纬度判断。
- 东西关系根据两条经线之间较短的经度弧判断，即“劣弧判读”。
- 经度间隔恰好为 180° 时，东西两侧的经度间隔相同，不能唯一确定东西关系。
- 地图可以沿 180° 经线展开，因此不能仅根据展开地图中两个地点的左右位置判断全球东西关系。

这里的“较短经度弧”是东西位置的判读约定，**不等于任意两点之间的球面最短航线**。

## 2. 为什么临界值是 180°

经度绕地球一周为 360°。从一条经线到另一条经线，向东和向西的经度间隔之和为 360°。

若向东跨 20°、向西跨 340°，按较短的一侧判断，目标点位于东侧。若两侧均为 180°，就没有唯一的较短一侧。

**“两个经度相加”只适用于一个是东经、另一个是西经；相加的是度数大小，不是带正负号的数值。**

### 一点东经、另一点西经

下表适用于两点均不在极点，且两点的经度度数分别严格处于 0°与 180°之间。

| 东经度数与西经度数之和 | 相对东西关系 |
| --- | --- |
| 小于 180° | 东经点在东，西经点在西 |
| 大于 180°、小于 360° | 西经点在东，东经点在西 |
| 等于 180° | 两条经线相对，不能唯一确定东西关系 |

0°没有东经／西经之分；180°E 与 180°W 是同一条经线。**0°经线与 180°经线彼此相对，并不是同一条经线。** 这些端点情况直接按经线关系判断。

### 两点同为东经或同为西经

- 同为东经：度数较大的点在东，较小的点在西。
- 同为西经：度数较小的点在东，较大的点在西。
- 判断间隔时取度数差，不能套用“度数相加”的规则。
- 若实际间隔达到 180°，仍按“东西等距”处理；同经线则没有东西差别。

## 3. 可以直接用于讲解的例子

以下例子均把 A、B 放在赤道上，排除南北差异，只讨论东西关系。

| A 点经度 | B 点经度 | 从 A 到 B 的较短经度弧 | B 相对 A |
| --- | --- | --- | --- |
| 170°E | 170°W | 向东 20°，跨越 180° 经线 | 东方 |
| 170°W | 170°E | 向西 20°，跨越 180° 经线 | 西方 |
| 20°E | 30°W | 向西 50°，经过 0° 经线 | 西方 |
| 20°E | 70°E | 向东 50° | 东方 |
| 20°W | 70°W | 向西 50° | 西方 |
| 20°E | 160°W | 向东、向西均为 180° | 不能唯一判定东西 |
| 180°E | 180°W | 同一条经线 | 在本表赤道条件下为同一点 |

以第一行为例：170°E 与 170°W 的度数之和为 340°。这不是说两点必须相隔 340°；另一侧只相隔 `360° − 340° = 20°`。由 170°E 向东跨越 180° 经线即可到达 170°W，所以 B 在 A 东侧。

> 给老师的讲解话术：地球是圆的，向东或向西绕行都能到达另一条经线。判断两点的相对东西位置时，我们约定取经度间隔较小的一侧。东经 170°和西经 170°之间，向东只跨 20°，所以后者在前者的东侧。展开地图的左右边缘是相接的，不能把它们当成地球的尽头。

## 4. 南北、极点和重合点

南北关系可把北纬记为正数、南纬记为负数进行比较：B 的纬度大于 A，B 在北侧；小于 A，B 在南侧；相等则没有南北差别。

| 情况 | 应怎样解释 |
| --- | --- |
| A、B 同经线、不同纬度 | 根据纬度判断南北；180°E 与 180°W 也属于同经线 |
| A、B 均非极点、同纬线，且较小经度间隔大于 0°、小于 180° | 按较短经度弧判断东西 |
| A、B 均非极点，两条经线相差 180° | 不能唯一确定东西；若纬度不同，南北关系仍可比较 |
| A 为北极点 | 所有离开北极点的方向都是南；不使用普通八方位盘 |
| A 为南极点 | 所有离开南极点的方向都是北；不使用普通八方位盘 |
| B 为北极点、A 为非极点 | B 在 A 的正北方向 |
| B 为南极点、A 为非极点 | B 在 A 的正南方向 |
| A、B 地理位置相同 | 没有唯一的 A→B 方向，不能默认显示“北方” |

两条经线相差 180°，不代表两点必然互为对跖点。**还需两点纬度互为相反数，才互为对跖点。**

课件把两点地表距离小于 1 米视为“过近”，提示重新选点，避免把点击误差当成稳定的方向。

## 5. 课件中的八方位与连线

### 八方位表示参考连线的方向角区间

课件以 A 点当地正北为 0°，顺时针计角：东为 90°、南为 180°、西为 270°。

| 显示方位 | 方位角区间 |
| --- | --- |
| 北 | [337.5°, 360°) 或 [0°, 22.5°) |
| 东北 | [22.5°, 67.5°) |
| 东 | [67.5°, 112.5°) |
| 东南 | [112.5°, 157.5°) |
| 南 | [157.5°, 202.5°) |
| 西南 | [202.5°, 247.5°) |
| 西 | [247.5°, 292.5°) |
| 西北 | [292.5°, 337.5°) |

`[a, b)` 表示包含 a、不包含 b；边界角划入顺时针的下一个区间。

这里的“八方位区间”与只比较经纬度的定性描述需要区分。例如，B 略偏东但明显偏北，按经纬度可以说它在 A 的东北侧；按课件的 45° 扇区归类，参考连线可能落入“北”区间。**“北方”区间不等于两点一定同经线。** 面板同时显示经纬度、方位角和向东／向西的经度间隔，供教师核对。

### 二维和三维使用同一条位置参考连线

- 二维地图采用 Web Mercator 投影，参考连线沿较短经度弧绘制。
- 例如 170°E→170°W，内部绘图坐标连续使用 `170°→190°`；190°是 170°W 的等价展开坐标，界面仍显示西经 170°。
- 卫星瓦片、经纬网、A/B 标记与连线在相邻世界副本上连续衔接。
- 三维地球沿用相同的经纬度路径，切换视图不另选一条路线。
- 三维视角中的屏幕上方不总是 A 点当地正北，应看 A 点周围的八方位辅助线。
- 相差 180° 时，虚线只示意其中一侧；所选绘图侧不构成唯一东西方向的结论。

该参考连线通常对应等角航线，课件显示的是沿它的方向角，**不是球面最短航线的起始航向**。远距离情况下，这两种方向可能不同。

## 6. 连线、实地距离和比例尺不能混为一谈

| 课件内容 | 含义 |
| --- | --- |
| A/B 黄色虚线 | 判断位置与方位的参考连线；通常不是最短航线 |
| “地表最短距离（球面估算）” | 根据两点经纬度计算的球面大圆最短距离；不是道路距离，也不是沿黄色虚线逐段累计的距离 |
| 卫星地图左下角比例尺 | Leaflet 自带的局部比例尺，适用于地图中心附近；与是否选了 A/B 无关 |
| 手动打开的“等距量图” | 以 A 为中心展开球面距离，用于比较从 A 出发的距离与标尺长度 |

Web Mercator 的距离比例随纬度变化，所以跨纬度、跨大范围的屏幕连线，不能直接用一把局部比例尺换算出地表最短距离。不能为了让像素倍数“对上”，修改真实距离或让标尺随选点改变。

“等距量图”也不是任意两点间都等距；它保证的是**从投影中心 A 出发**的地表最短距离按比例展开。

## 7. 经纬度显示约定

- 经度标明东经／西经，纬度标明北纬／南纬。
- 使用度分格式，例如 `北纬 23°26′`；分钟可以保留小数，方便校园尺度定位。
- 经度 0°标明本初子午线；纬度 0°标明赤道。
- A/B 坐标栏中的 180°不再附加东经或西经，因为二者是同一条经线。
- 极点坐标栏提示“无唯一经度”，避免把存储的经度数值当成极点的唯一位置描述。
- 世界副本坐标先归一化再显示，例如 190°显示为西经 170°，370°显示为东经 10°。
- 交换 A/B 只交换参照点与目标点，实际地理位置不变，坐标栏和方位结果同步更新。

不要把 180° 经线与现实中的国际日期变更线完全等同；后者并非处处沿 180° 经线。本课件这里处理的是经度连续性和方位判读。

## 8. 实现与维护核对

### 经度归一化的核心步骤

东经为正、西经为负。设原始差值 `d = B.lng - A.lng`：

```text
eastward = ((d % 360) + 360) % 360

eastward ≈ 0°（或360°） → 同经线
eastward ≈ 180°         → 东西等距，不唯一判定
0° < eastward < 180°    → B在A东侧，短弧差为 eastward
180° < eastward < 360°  → B在A西侧，短弧差为 eastward - 360°
```

实现对 0°与 180°采用 `1e-9` 度容差处理浮点误差。180°时可以保留一个符号作为可重复的绘图约定，但不得把这个符号直接当作东西判读结果。

方位角使用归一后的经度差和 Mercator 纵坐标差计算：

```text
ψ(φ) = asinh(tan(φ))                 // φ以弧度表示
θ = atan2(短弧经度差的弧度, ψ(B纬度) - ψ(A纬度))
方位角 = 把θ换算为角度，并归一到[0°, 360°)
```

极点、相差 180°及重合点应在套用普通方位角逻辑之前单独处理。地理纬度不能为了计算方向而裁剪到卫星影像的 ±85.051°范围，否则会把不同的极区纬度错误地当成相同纬度。

## 9. 之前为什么会判断错误，以及解决办法

之前的问题主要出在课件的计算规则与显示路径没有统一，不能简单归咎于卫星影像。排查时应分清：**经度回绕错误、极区纬度处理错误、不同方位概念混用，以及图形与文字不同步**。

### 9.1 直接相减经度，把短侧误判成长侧

**之前的处理：** 为了匹配展开地图上的直线，方向计算直接使用 `B.lng - A.lng`，参考连线也保留展开后的长路径，没有归一到较短经度弧。

例如 A=170°E、B=170°W，带符号的经度分别是 `+170`、`−170`：

```text
旧的直接差值：−170 − 170 = −340° → 按负值判西
应使用的短弧：−340° + 360° = +20° → 按劣弧判东
```

旧结果可以与画面上向左画出的长连线一致，却不符合本课件所需的全球劣弧判读规则。这是本次“地球自转课件已判东、地图课件却判西”的直接原因。

**解决办法：**

1. 使用 `compareLongitudes` 统一计算较短经度弧。
2. 普通情况下以短弧差的正负判断东西；相差 180°单独返回“不唯一”，不硬判东或西。
3. 参考连线使用相同短弧，让示例沿 `170°→180°→190°` 绘制。
4. 对外显示归一后的经度，仍标注为 170°E 与 170°W，不把展开坐标 190°误当成新的地理位置。

**验证方法：** 170°E→170°W 判东；交换后判西；把任一点存储经度加减 360°，地理判断不变；180°前后与恰好 180°分别检查。

### 9.2 把卫星影像的纬度裁剪范围用于地理计算

**之前的问题：** Web Mercator 影像显示通常裁剪到约 ±85.051°。如果方位计算也把原始纬度裁剪到这个范围，极区不同地点就会被压成同一个纬度。

例如，同一经线上从 87°N 的 A 指向 86°N 的 B，应当向南；若两者都被裁剪成约 85.051°N，南北差异就消失，后续计算可能产生“北方”或无法正确判读的结果。

**解决办法：**

1. 地理计算保留真实纬度，不套用影像裁剪范围。
2. 投影数值在接近极点处采用稳定处理，避免无穷值。
3. 精确极点单独判读；A 为极点时不生成普通八方位结论或辅助盘。
4. 同时修正位置参考路径，避免三维极区连线退回 85°附近。

**验证方法：** 同经线 87°N→86°N 为南，交换为北；南极附近对应例子也检查；精确极点与非常接近极点的普通点分别检查。

### 9.3 把最短航线的起始航向当成两点相对方位

这是另一种会造成“图上在西南，文字却说西北”的计算口径问题，不能与经度回绕错误混为一谈。

**为什么会发生：** 大圆最短航线可能先向更高纬度出发，再转向目标点。它的“起始航向”描述出发时朝哪里走，并不直接等于目标点按经纬关系位于哪一侧。

例如 A=(80°N, 170°E)、B=(30°N, 30°E)：

- B 的纬度更低，较短经度方向为西，因此相对位置在西南侧。
- 球面最短航线的起始航向约为 323°，落在西北区间。
- 本课件沿较短经度弧的位置参考连线，其方向角约为 232°，落在西南区间。

这组差异并不能说明大圆公式本身错误，而是说明它回答的是另一个问题。**不能把航线的起始航向直接放到“B 在 A 的什么方向”之下，又配上一条不同路径的直线。**

**解决办法：** 方位阶段沿用统一的位置参考连线和对应方向角；最短距离另行计算并明确标为“球面最短距离”。未来若增加最短航线教学，应单列“起始航向”和大圆路径，不能静默替换现有方位含义。

### 9.4 只改方向文字，遗漏二维／三维路径和标记

**会出现的现象：** 面板已经判东，但连线仍向西绕远；路线终点与 B 标记分离；切换三维后路线换了一侧；跨 180°经线时影像出现空白或过渡变暗。

**原因：** 判读、参考路径、A/B 标记、瓦片与经纬网分别处理经度，使用了不同的世界副本；旧的三维纹理裁剪还可能只允许显示一个展开世界。

**解决办法：**

- 二维与三维共用 `mapReferencePath` 生成的经纬度路径。
- 标记使用路径的对应端点，避免相差 360°的等价坐标被画到不同边缘。
- 地图移动后，重新计算当前可见的路线与标记副本。
- Leaflet 瓦片允许经度循环；经纬网几何可以连续展开，但标签归一化。
- 清除与循环底图不一致的三维单世界纹理裁剪，使过渡两侧都有影像。

**验证方法：** 围绕 180°经线选点，观察短连线是否连接 A/B；平移跨过经线，交换 A/B，再执行二维→三维→二维切换，核对坐标、方向和经过地点；同时检查手机尺寸。

### 9.5 为什么之前的测试没有拦住

此前有一条测试把“保留展开地图上的长路径方向”作为预期结果，相当于把旧实现的行为当成了正确规则。因此，即使测试通过，也无法证明符合本课件需要的劣弧判读规则。

**改进方法：** 先写出独立于代码实现的地理事实与人工例子，再验证实现。不能仅以“文字和旧连线一致”作为通过标准。

维护时至少同时检查三层：

1. **规则正确：** 170°E→170°W 应向东；180°不唯一；极点另行处理。
2. **计算正确：** 交换 A/B、经度加减整周、高纬与边界输入的结果符合规则。
3. **呈现正确：** 经纬度、文字、辅助线、二维与三维路径使用一致的地理位置和判读口径。
