## 1. 总体思路（一句话）

**地球不用 Three 的内置材质，也不用 Three 的灯光。** 整个昼面/夜面/夜光/海洋高光/晨昏线/夜弧/内层大气全部写在一个手写的 `THREE.ShaderMaterial` 片元着色器里，光照只依赖一个 `sunDirection` uniform；外层大气辉光是**第二层球壳**（`BackSide` + 深度遮挡）单独画的。

```
scene
├── galaxySkyDome        r=72    ShaderMaterial / BackSide / depthTest=false / renderOrder=-10000
├── sunLight, ambientLight       ← 存在但不影响地球（见 §8 注意点）
├── subsolarMarker               ← applyLayerVisibility() 中恒设 visible=false
└── earthGroup           rotation.z = TILT(23.5°)
    ├── earthMesh        r=2     ShaderMaterial（本文主角），rotation.y = rotationAngle 逐帧递增
    │   ├── graticuleGroup          经纬网       r=2×1.003
    │   ├── dateLineGroup           日界线/本初子午线
    │   ├── timeZoneGroup           时区线（默认隐藏）
    │   ├── timeZoneRangeGroup      时区范围贴图壳 r=2×1.006，renderOrder=8（默认隐藏）
    │   ├── coriolisGroup           地转偏向力箭头（默认隐藏）
    │   ├── rotationArrowGroup      自转方向箭头 r=2×1.015
    │   └── cityMarkers[]           城市小球     r=2×1.01
    ├── earthAtmosphere  r=2.11  ShaderMaterial / BackSide / transparent，renderOrder=2
    └── axisLine         自转轴
```

关键常量：

```ts
const EARTH_RADIUS = 2
const TILT = 23.5 * Math.PI / 180
const NIGHT_ARC_COLOR = '#8d86ff'                              // 夜弧
const atmosphereDayColorUniform     = { value: new THREE.Color('#4db2ff') }  // 大气·昼
const atmosphereTwilightColorUniform = { value: new THREE.Color('#bc490b') } // 大气·晨昏
```

渲染器 / 相机：

```ts
renderer.outputColorSpace = THREE.SRGBColorSpace
renderer.toneMapping       = THREE.ACESFilmicToneMapping
renderer.toneMappingExposure = 1.05
renderer.setPixelRatio(Math.min(window.devicePixelRatio || 1, 2))

camera = new THREE.PerspectiveCamera(50, w / h, 0.1, 200)   // position (0, 2, 7)
scene.background = new THREE.Color(0x000511)

controls.minDistance = 3.5
controls.maxDistance = 20
controls.dampingFactor = 0.08
```

球体细分：`new THREE.SphereGeometry(EARTH_RADIUS, 96, 96)`，地球与大气壳都是 96×96。

## 2. 贴图

### 2.1 资源清单

```ts
const TEXTURE_BASE = '/geo-resources-folder/images'
const RAW_TEXTURES = {
  earth: `${TEXTURE_BASE}/Material.002_diffuse.jpg`,  // 昼面 albedo
  night: `${TEXTURE_BASE}/emissive.jpg`,              // 夜间灯光 emissive
}
const GALAXY_SKYBOX_URL = `${TEXTURE_BASE}/milky-way-6k.jpg`  // 银河等距柱状图
```

`/geo-resources-folder` 在 `vite.config.ts` 里被代理到 `https://zdys.szjx.ai-study.net/`，本地 `public/` 下**没有**这些图片，因此开发态必须走 dev server 代理，生产态需同源部署。

| 用途 | 文件 | 进入哪个 uniform | 备注 |
| --- | --- | --- | --- |
| 昼面地表 | `Material.002_diffuse.jpg` | `dayMap` | 同时被拿来**反推海洋/云掩码**和暗面补光 |
| 夜间灯光 | `emissive.jpg` | `nightMap` | 只在夜半球可见 |
| 银河背景 | `milky-way-6k.jpg` | `skyMap`（天空盒材质） | 等距柱状投影，见 §5 |

> 没有使用 normal / roughness / specular / cloud 独立贴图，也没有 CubeTexture。海洋高光与云层都是从 `dayMap` 的颜色统计推导出来的（见 §3.4）。

### 2.2 加载与首屏遮罩

三张贴图共用一个 `THREE.LoadingManager`，全部就绪后才揭开页面：

```ts
const textureLoadingManager = new THREE.LoadingManager()
textureLoadingManager.onLoad     = () => { sceneReady.value = true; loadingProgress.value = 100; ... }
textureLoadingManager.onProgress = (_url, loaded, total) => { loadingProgress.value = ... }
textureLoadingManager.onError    = (url) => { console.warn('贴图加载失败:', url) }  // 不阻塞
```

- 模板里 `v-if="!sceneReady"` 的 `.page-loading-overlay` 显示 spinner + 进度条（`aria-valuenow` 绑定 `loadingProgress`）。
- 兜底：`onMounted` 里挂一个 **20s** 的 `loadingSafetyTimer`，若某张图既不 `onLoad` 也不 `onError`（请求挂起）则强制 `sceneReady = true`；`onLoad` 与 `onUnmounted` 都会清掉它。

### 2.3 程序化兜底贴图（先占位，后替换）

`initThree()` 在发起网络请求**之前**，先用 Canvas 生成的贴图填上 uniform，保证第一帧就有地球：

```ts
earthUniforms.dayMap.value   = createEarthTexture()          // 2048×1024 CanvasTexture
earthUniforms.nightMap.value = createNightEmissiveTexture()  // 2048×1024 纯黑
```

- **`createEarthTexture()`**：2048×1024 画布。
  - 海洋：`createLinearGradient` 竖向三段 `#1a3a6e → #1e4a8a → #1a3a6e`。
  - 大陆：内置 7 组简化 `[lon, lat]` 多边形（北美 / 南美 / 非洲 / 欧亚 / 澳大利亚 / 格陵兰 / 南极洲），按 `(lon+180)/360*w`、`(90-lat)/180*h` 投影到画布；填充用中心 `#3a7d44` → 边缘 `#2d5a3d` 的 `createRadialGradient`，描边 `#1a3a2a`，`lineWidth=2`。
  - 沙漠：三个 `rgba(200,170,100,0.35)` 椭圆（撒哈拉 180×80、阿拉伯 80×60、澳洲内陆 70×50）。
  - 输出 `THREE.CanvasTexture`，`colorSpace = SRGBColorSpace`。
- **`createNightEmissiveTexture()`**：同尺寸**纯黑**画布。注释明确写了原因——真实 `emissive.jpg` 到位前保持全黑，避免首屏出现一大块黄色。

真实贴图加载成功后直接覆盖同名 uniform（材质是同一个对象，无需重建）：

```ts
const prepareEarthTexture = (texture: THREE.Texture) => {
  texture.colorSpace   = THREE.SRGBColorSpace
  texture.anisotropy   = Math.min(8, renderer.capabilities.getMaxAnisotropy())
  texture.minFilter    = THREE.LinearMipmapLinearFilter
  texture.magFilter    = THREE.LinearFilter
  texture.generateMipmaps = true
  texture.needsUpdate  = true
}

texLoader.load(RAW_TEXTURES.earth, tex => { prepareEarthTexture(tex); earthUniforms.dayMap.value = tex },
               undefined, err => console.warn('地球贴图加载失败，使用程序化纹理:', err))
texLoader.load(RAW_TEXTURES.night, tex => { prepareEarthTexture(tex); earthUniforms.nightMap.value = tex },
               undefined, err => console.warn('夜间灯光 emissive 贴图加载失败，使用程序化夜光贴图:', err))
```

## 3. 地球主 ShaderMaterial

### 3.1 Uniforms

```ts
const earthUniforms = {
  dayMap:   { value: null as THREE.Texture | null },
  nightMap: { value: null as THREE.Texture | null },
  sunDirection:  { value: new THREE.Vector3(1, 0, 0) },
  axisDirection: { value: new THREE.Vector3(0, 1, 0).applyAxisAngle(new THREE.Vector3(0, 0, 1), TILT) },
  showTerminator: { value: 1 },   // 晨昏线开关
  showNightArc:   { value: 1 },   // 夜弧开关
  showGraticule:  { value: 1 },   // 经纬网开关（影响夜弧在赤道附近的抑制）
  nightArcColor:  { value: new THREE.Color(NIGHT_ARC_COLOR) },
  sunLightPower:        { value: 1.35 },
  nightMapPower:        { value: 1.8 },
  nightLightPower:      { value: 1.65 },
  darkSideSurfacePower: { value: 0.42 },
  atmosphereDayColor:      atmosphereDayColorUniform,      // ← 与外层大气壳共用同一对象
  atmosphereTwilightColor: atmosphereTwilightColorUniform, // ← 同上
}
```

材质本体：`new THREE.ShaderMaterial({ uniforms: earthUniforms, toneMapped: true, vertexShader, fragmentShader })` —— **没有 `lights: true`**，所以 `sunLight` / `ambientLight` 完全不参与地球着色。

### 3.2 顶点着色器

```glsl
varying vec2 vUv;
varying vec3 vLocalNormal;   // 物体空间法线 → 用于算「纬度」（不随自转漂移）
varying vec3 vWorldNormal;   // 世界空间法线 → 用于算昼夜、高光、菲涅尔
varying vec3 vWorldPosition; // → 用于算视线方向

void main() {
  vUv = uv;
  vLocalNormal = normalize(normal);
  vec4 worldPosition = modelMatrix * vec4(position, 1.0);
  vWorldPosition = worldPosition.xyz;
  vWorldNormal = normalize(mat3(modelMatrix) * normal);
  gl_Position = projectionMatrix * viewMatrix * worldPosition;
}
```

> **为什么需要两套法线**：昼夜、高光、晨昏线都是世界空间的（太阳方向固定，地球在转）；而「夜弧 = 纬线在夜半球的那一段」必须按**地理纬度**判断，纬度属于物体空间，用世界法线会随 `earthMesh.rotation.y` 一起转走。

### 3.3 片元着色器 · 完整流水线

着色顺序是**刻意的**，后一步覆盖前一步，注释里也点明了原因。

```glsl
// 工具函数
float earthLuma(vec3 color) { return dot(color, vec3(0.2126, 0.7152, 0.0722)); } // Rec.709 亮度

float latitudeLineMask(float lat) {          // 每 15° 一条纬线
  float stepValue = 3.14159265359 / 12.0;    // π/12 = 15°
  float shifted = mod(lat + 1.57079632679 + stepValue * 0.5, stepValue) - stepValue * 0.5;
  return 1.0 - smoothstep(0.004, 0.014, abs(shifted));
}
```

**① 基础向量与采样**

```glsl
vec3 nWorld = normalize(vWorldNormal);
vec3 sWorld = normalize(sunDirection);
vec3 viewDirection = normalize(cameraPosition - vWorldPosition);

vec3 dayColor = texture2D(dayMap, vUv).rgb;
dayColor = pow(max(dayColor, vec3(0.0)), vec3(1.08));  // 轻微压暗/提对比
vec3 nightColor = texture2D(nightMap, vUv).rgb;
```

**② 昼夜掩码（两套！）**

```glsl
float lightAmount = dot(nWorld, sWorld);              // 太阳高度角的余弦

// (a) 地表明暗：宽渐变，为了柔和的黄昏过渡
float dayMask  = smoothstep(-0.24, 0.34, lightAmount);
float nightMask = 1.0 - dayMask;

// (b) 几何夜半球：严格按太阳高度 0° 截取，供夜弧使用
float nightEdgeWidth = max(fwidth(lightAmount), 0.00001);
float geometricNightMask = 1.0 - smoothstep(-nightEdgeWidth, 0.0, lightAmount);
```

这是本页最重要的一个设计点，注释原文：

> 地表明暗使用宽渐变；夜弧的几何范围必须**单独**按太阳高度 0° 截取。

- `dayMask` 的过渡带宽达 `[-0.24, 0.34]`（约 ±76°~±70° 太阳高度），视觉上黄昏很长、很柔。
- `geometricNightMask` 用 `fwidth()` 求屏幕空间导数，把过渡带压到**一个像素**，因此夜弧的边界就是天文学上的晨昏圈；且抗锯齿**只向夜侧**过渡，昼侧恒为 0，不会出现"白昼侧也画半条弧"。
- 由此自然得到：极夜纬线整圈可见，极昼纬线完全隐藏。

**③ 海洋 / 云层掩码（从 albedo 反推，无独立贴图）**

```glsl
float surfaceLuma    = earthLuma(dayColor);
float blueDominance  = dayColor.b - max(dayColor.r, dayColor.g);
float oceanMask = smoothstep(-0.025, 0.115, blueDominance)
                * (1.0 - smoothstep(0.48, 0.82, surfaceLuma));
float cloudMask = smoothstep(0.64, 0.94, surfaceLuma) * (1.0 - oceanMask * 0.72);
```

判据：
- **海洋** = 「蓝通道明显高于红绿」且「整体不太亮」。第二个因子用来剔除白雪/浅色沙漠这类也可能偏蓝的高亮像素。
- **云** = 「非常亮」，并用 `(1 - oceanMask*0.72)` 避免把亮海面误判成云。

**④ 昼面着色**

```glsl
float directLight = max(lightAmount, 0.0);
vec3 litDay = dayColor * (0.18 + sunLightPower * 0.58 * directLight);
litDay *= mix(1.0, 1.02, cloudMask);                       // 云略提亮 2%
litDay *= mix(vec3(1.0), vec3(0.74, 0.86, 1.0), oceanMask * 0.48);  // 海面偏冷蓝
```

`0.18` 是昼面最低环境底光；`brightness` 滑杆（默认 1.2）通过 `sunLightPower` 控制正午亮度，满照时系数约 `0.18 + 1.2×0.58 ≈ 0.876`。

**⑤ 海洋高光（Blinn-Phong）**

```glsl
vec3 halfDirection = normalize(sWorld + viewDirection);
float specularPower = mix(28.0, 105.0, oceanMask);         // 陆地 28（很钝）→ 海面 105（很锐）
float specular = pow(max(dot(nWorld, halfDirection), 0.0), specularPower)
               * oceanMask * directLight * dayMask;
vec3 oceanGlint = mix(vec3(0.40, 0.64, 0.82), vec3(1.0), specular)
                * specular * (0.42 + sunLightPower * 0.22);
```

要点：
- 半程向量 `H = normalize(L + V)`，即标准 Blinn-Phong，比原始 Phong 便宜且高光更圆润。
- `specularPower` 用 `oceanMask` 做插值，**同一份材质里陆地和海面拥有不同的粗糙度**——这是「没有 roughness 贴图也能出海洋镜面反射」的关键。
- 三重门控 `oceanMask * directLight * dayMask`：只在海面、只在朝向太阳、只在昼半球出现。所以夜半球不会有假反光，晨昏线附近高光自然淡出。
- 高光色由冷蓝 `(0.40,0.64,0.82)` 向纯白过渡，强度随 `sunLightPower` 微升（默认约 `0.684`）。

**⑥ 夜间灯光 + 暗面补光**

```glsl
vec3 nightLit = nightColor * nightMapPower * (0.26 + nightLightPower) * nightMask;

float rimFill = 0.48 + 0.52 * pow(1.0 - abs(lightAmount), 0.72);
vec3 darkSurface = dayColor * darkSideSurfacePower * 0.34 * rimFill * nightMask;

vec3 color = mix(darkSurface + nightLit, litDay + oceanGlint, dayMask);
```

- `nightLit`：夜光贴图 × `nightMapPower`(1.8) × `(0.26 + nightLightPower)` × `nightMask`。默认滑杆值 0.3 → 总增益约 `1.8 × 0.56 ≈ 1.0`。`nightMask` 用的是**宽渐变**那套，所以城市灯光在黄昏带就开始渐显，不会硬切。
- `darkSurface`：拿**昼面贴图**当"月光/环境反光"给夜半球一层极暗的底色，让大陆轮廓仍可辨认。
  - `rimFill = 0.48 + 0.52·(1-|lightAmount|)^0.72`，在晨昏线处（`lightAmount≈0`）取最大值 1.0，在正对/正背太阳处降到 0.48 —— 模拟晨昏附近更长的大气散射路径。
  - `darkSideSurfacePower` 默认滑杆 0.05，最终系数 `0.05 × 0.34 × rimFill ≈ 0.008~0.017`，非常克制。
- 最后用 `dayMask` 把「夜半球(暗底+灯光)」和「昼半球(受光+海面高光)」混合成一张图。

**⑦ 夜弧（纬线在夜半球的部分）**

```glsl
float lat = asin(clamp(normalize(vLocalNormal).y, -1.0, 1.0));   // 物体空间纬度

float nightArcMask = latitudeLineMask(lat) * geometricNightMask * showNightArc;
// 网格开启时赤道使用独立红线，避免夜弧的宽紫色高亮在红线两侧形成紫边。
nightArcMask *= mix(1.0, smoothstep(0.014, 0.018, abs(lat)), showGraticule);

color = mix(color, nightArcColor, nightArcMask * 0.76);
```

- 纬线宽度由 `latitudeLineMask` 的 `smoothstep(0.004, 0.014, …)` 决定，即约 0.23°~0.80° 纬度带宽（`0.004 rad ≈ 0.229°`）。
- 用 `geometricNightMask`（②的严格版本）裁切 → 只剩夜半球弧段。
- 最后一行是**去紫边**技巧：当经纬网开启时，`|lat| < 0.018 rad (≈1°)` 范围内的夜弧被压掉，把赤道让给 `createGraticule()` 里那条独立的红色 `TorusGeometry`。
- `createNightArcShader()` 已被掏空，只 `return new THREE.Group()`，注释说明夜弧**不再**是独立的三维线对象；`updateNightArcShader()` 也只剩一行开关同步。

**⑧ 晨昏线（晨线蓝 / 昏线红）**

```glsl
float terminatorMask = (1.0 - smoothstep(0.0, 0.035, abs(lightAmount))) * showTerminator;
float dawnSignal = dot(cross(normalize(axisDirection), nWorld), sWorld);
vec3 dawnColor = vec3(0.12, 0.38, 0.56);   // = #1f618f
vec3 duskColor = vec3(0.56, 0.12, 0.22);   // = #8f1f38
color = mix(color, dawnSignal >= 0.0 ? dawnColor : duskColor, terminatorMask * 0.52);
```

- 判据是 `|lightAmount| < 0.035` 的一条窄带（约 2° 太阳高度），比地表明暗带窄得多，因此是一条清晰的线。
- **晨/昏区分**：`cross(axisDirection, nWorld)` 得到该点所在经圈的切向，再与太阳方向点乘判正负。`axisDirection` 是 `(0,1,0)` 绕 Z 轴倾 23.5°，与 `earthGroup.rotation.z` 一致。
- 颜色与页面左下图例的 CSS 完全对应：`.legend-line` 用 `#1f618f`（晨线·日出）与 `#8f1f38`（昏线·日落）。
- 注释：「在夜弧之后着色，保持交点清晰」。

**⑨ 内层大气边缘（地表上的 Fresnel 蓝边）**

```glsl
float atmosphereDayStrength = smoothstep(-0.5, 1.0, lightAmount);
float atmosphereFresnel = 1.0 - abs(dot(nWorld, viewDirection));
vec3 innerAtmosphereColor = mix(
  atmosphereTwilightColor, atmosphereDayColor,
  smoothstep(-0.25, 0.75, lightAmount)
);
float innerAtmosphereMix = clamp(
  atmosphereDayStrength * pow(atmosphereFresnel, 2.0) * 0.46, 0.0, 0.46
);
color = mix(color, innerAtmosphereColor, innerAtmosphereMix);
```

- 只在**视线掠射角**（`fresnel→1`，即地球轮廓内侧）混入大气色，`pow(…, 2.0)` 让衰减很快，`clamp(…, 0, 0.46)` 封顶。
- 注释强调：「只在视角边缘混合大气颜色，**不向背光地表叠加蓝色补光**」——避免夜半球被洗成蓝色。
- 颜色随太阳高度从黄昏橙 `#bc490b` 过渡到昼蓝 `#4db2ff`，与外层大气壳共用同一对 `THREE.Color` 对象，所以内外层色相天然一致。

**⑩ 输出**

```glsl
gl_FragColor = vec4(color, 1.0);
#include <tonemapping_fragment>   // ACESFilmic
#include <colorspace_fragment>    // → sRGB
```

两个 `#include` 让手写 shader 也能吃到 renderer 上的色调映射与色彩空间设置，和内置材质表现一致。

## 4. 大气层（外层辉光壳）

独立的一层球壳，加在 `earthGroup` 下（跟着地轴倾，不跟着自转——因为是球对称的，转不转看不出来）：

```ts
earthAtmosphere = new THREE.Mesh(
  new THREE.SphereGeometry(EARTH_RADIUS * 1.055, 96, 96),   // r = 2.11
  atmosphereMaterial,
)
earthAtmosphere.renderOrder = 2
earthGroup.add(earthAtmosphere)
```

材质状态：

```ts
new THREE.ShaderMaterial({
  uniforms: earthAtmosphereUniforms,   // { sunDirection, atmosphereDayColor, atmosphereTwilightColor }
  transparent: true,
  blending: THREE.NormalBlending,      // 注意：不是 AdditiveBlending
  depthWrite: false,
  depthTest: true,
  side: THREE.BackSide,
  toneMapped: true,
})
```

**原理**（源码注释：「背面壳层由地球深度遮挡，只在轮廓外呈现渐隐辉光」）：

1. `side: BackSide` → 只画壳的**远侧**半球，近侧不画，因此绝不会糊在地球表面之上。
2. `depthTest: true` + 地球是 `depthWrite` 的不透明体 → 屏幕上半径 < 2 的区域（地球圆盘）全部深度测试失败被丢弃。
3. 于是真正可见的只剩 **r=2 到 r=2.11 之间的一圈环带**，也就是"大气层厚度"。
4. `depthWrite: false` + `renderOrder = 2` → 不污染深度缓冲，且排在时区贴图壳（`renderOrder = 8`）之前。

片元着色器：

```glsl
vec3 normalDirection = normalize(vWorldNormal);
vec3 viewDirection   = normalize(cameraPosition - vWorldPosition);

float fresnel        = 1.0 - abs(dot(normalDirection, viewDirection));
float sunOrientation = dot(normalDirection, normalize(sunDirection));

float daylight      = smoothstep(-0.5, 1.0, sunOrientation);   // 夜侧无辉光
float atmosphereMix = smoothstep(-0.25, 0.75, sunOrientation); // 橙 → 蓝
float innerEdge     = 1.0 - smoothstep(0.67, 1.0, fresnel);    // 靠近地球边缘最亮，向外淡出
float alpha         = pow(innerEdge, 2.65) * daylight;

if (alpha < 0.004) discard;                                    // 省填充率

vec3 glowColor = mix(atmosphereTwilightColor, atmosphereDayColor, atmosphereMix);
gl_FragColor = vec4(glowColor * 1.08, min(alpha * 1.10, 1.0));
#include <tonemapping_fragment>
#include <colorspace_fragment>
```

环带内 `fresnel` 的取值范围可以算出来：球面上投影半径为 ρ 的点满足 `|dot(n,v)| = √(1-(ρ/2.11)²)`，所以

| 位置 | ρ | `fresnel` | `innerEdge` | `alpha`（昼侧） |
| --- | --- | --- | --- | --- |
| 环带内缘（贴地球轮廓） | 2.00 | ≈0.684 | ≈0.995 | ≈0.99 |
| 环带中点 | 2.06 | ≈0.835 | ≈0.50 | ≈0.16 |
| 环带外缘（壳自身轮廓） | 2.11 | ≈1.000 | 0 | 0 |

即**内亮外暗**，正是大气辉光应有的衰减方向；`pow(…, 2.65)` 让它压得很薄。`smoothstep` 的下界 `0.67` 是刻意卡在环带内缘的 0.684 之下的，等于让整条可见环带都落在衰减区间里，一点不浪费。

`daylight` 与地球 shader 里 `atmosphereDayStrength` 用的是**同一个 `smoothstep(-0.5, 1.0, …)`**，`atmosphereMix` 也与内层 `smoothstep(-0.25, 0.75, …)` 对齐——内外两层的昼夜渐变节奏完全同步，交界处不会出现断层。

## 5. 银河天空盒

```ts
texture.mapping    = THREE.EquirectangularReflectionMapping
texture.colorSpace = THREE.SRGBColorSpace
texture.wrapS = THREE.RepeatWrapping
texture.wrapT = THREE.ClampToEdgeWrapping
texture.generateMipmaps = false
texture.minFilter = texture.magFilter = THREE.LinearFilter
texture.anisotropy = Math.min(8, renderer.capabilities.getMaxAnisotropy())

galaxySkyDome = new THREE.Mesh(new THREE.SphereGeometry(72, 128, 64), material)
galaxySkyDome.rotation.x = -0.4
galaxySkyDome.frustumCulled = false
galaxySkyDome.renderOrder = -10000
galaxySkyDome.visible = layers.stars
scene.add(galaxySkyDome)   // 注意：挂在 scene 上，不在 earthGroup 内
```

顶点着色器用经典「去掉相机平移」的 skybox 技巧，让穹顶永远"无穷远"：

```glsl
mat4 viewRotation = mat4(mat3(viewMatrix));
gl_Position = projectionMatrix * viewRotation * vec4(position, 1.0);
```

片元着色器做了一次 **4 邻域反锐化掩模**，把 6k 银河图压暗并锐化星点：

```glsl
vec2 uv = vec2(1.0 - vUv.x, vUv.y);            // 水平镜像，修正等距柱状图朝向
vec3 center = texture2D(skyMap, uv).rgb;
vec3 neighbors = ( 右 + 左 + 上 + 下 ) * 0.25;
vec3 color = max(center + (center - neighbors) * sharpness, 0.0) * exposure;
// exposure = 0.105, sharpness = 1.65
```

`depthTest: false` + `depthWrite: false` + `renderOrder = -10000` 保证它永远在最底层。加载失败只 `console.warn('银河天空盒加载失败，已保留深色背景')`，`scene.background`（`0x000511`）兜底。

重建时（重复调用 `loadGalaxySkybox`）会先 `removeFromParent()` 并 dispose 旧的 geometry / material / texture，再赋新值，不泄漏。

## 6. 太阳方向的计算

```ts
const sunDirection  = new THREE.Vector3(1, 0, 0)
const earthTiltAxis = new THREE.Vector3(0, 0, 1)

function updateSolarTermScene() {
  const declination = THREE.MathUtils.degToRad(solarDeclinationDeg.value)
  // 先在地球本地坐标中构造直射纬度，再应用固定的 23.5° 地轴倾角。
  // 冬至时结果仍接近原来的世界坐标 +X，保证默认画面不突变。
  sunDirection
    .set(Math.cos(declination), Math.sin(declination), 0)
    .applyAxisAngle(earthTiltAxis, TILT)
    .normalize()

  earthUniforms.sunDirection.value.copy(sunDirection)
  earthAtmosphereUniforms.sunDirection.value.copy(sunDirection)
  if (sunLight) sunLight.position.copy(sunDirection).multiplyScalar(10)
}
```

- 赤纬 `solarDeclinationDeg` 由所选**二十四节气**推出（`getSolarTermDeclination(index, 23.5)`，见 `./time-model.ts`），默认节气为**冬至**。
- 触发：`watch(selectedSolarTermName, () => updateSolarTermScene())`。
- 注意 `axisDirection` uniform 是在声明时**一次性**算好的 `(0,1,0)` 绕 Z 倾 23.5°，之后不再更新——因为它表达的是地轴指向，恒定不变。

## 8. 注意点与可优化项

以下是阅读代码时发现的现状，**未做任何修改**，供后续判断：

1. **`sunLight` / `ambientLight` 对地球无实际作用。**
   `initThree()` 里创建了 `DirectionalLight(0xffffff, 3.5)` 与 `AmbientLight(0x4a5a8a, 0.9)`，`applyLayerVisibility()` 还会按 `brightness` 缩放它们的 `intensity`，`updateSolarTermScene()` 会移动 `sunLight.position`。但地球的 `ShaderMaterial` 没有开 `lights: true`，页面里其余可见对象用的都是 `MeshBasicMaterial` / `LineBasicMaterial`（同样不受光）。这两个灯目前可以视为**遗留代码**。

2. **uniform 字面量默认值与运行时值不一致。**
   `nightLightPower` 声明为 `1.65`、`darkSideSurfacePower` 声明为 `0.42`、`sunLightPower` 声明为 `1.35`，但 `animate()` 每帧都会用 ref 值（`0.3` / `0.05` / `1.2`）覆盖。直接读 `earthUniforms` 声明会误判初始观感。

3. **`sunDirection` 在两个 uniform 对象里是各自独立的 `Vector3`。**
   `updateSolarTermScene()` 会同时 copy 到两边，但 `animate()` 每帧只 copy 到 `earthUniforms.sunDirection`。当前逻辑下太阳方向只在切节气时变化，因此不出问题；若将来加入太阳方向逐帧变化（如公转），需要同步补上 `earthAtmosphereUniforms.sunDirection`。

4. **两个大气颜色 uniform 是共享对象。**
   `atmosphereDayColorUniform` / `atmosphereTwilightColorUniform` 被 `earthUniforms` 与 `earthAtmosphereUniforms` 同时引用，改一处内外层同步变色——这是有意的，改动时注意别拆开。

5. **`fwidth()` 的可用性。**
   `geometricNightMask` 依赖屏幕空间导数。three r184 默认 WebGL2，`fwidth` 是核心功能，无需扩展；但如果将来降级到 WebGL1 需要 `GL_OES_standard_derivatives`。

6. **海洋/云掩码依赖具体贴图的色彩分布。**
   `blueDominance` 与 `surfaceLuma` 的阈值（`-0.025/0.115`、`0.48/0.82`、`0.64/0.94`）是针对 `Material.002_diffuse.jpg` 调出来的。换地表贴图必须重新标定，否则会出现「沙漠反光」或「海面不出高光」。

7. **贴图必须走代理。**
   `public/` 下没有 `geo-resources-folder/`，直接 `vite build` 后离线打开会全部回落到程序化 Canvas 贴图（昼面是简笔画大陆，夜面全黑）。

8. **资源释放。**
   `onUnmounted` 里 cancel 了 `animationId` 与两帧 resize rAF、清了 resize timer 与 20s 安全 timer、断开两个 `ResizeObserver`、移除 pointer/click 监听、`controls.dispose()`、`renderer.dispose()`、`galaxySkyboxTexture.dispose()`，并 `scene.traverse` 对所有 `Mesh` 逐个 dispose geometry / material。**贴图本身（`dayMap` / `nightMap`）没有显式 dispose**，只 dispose 了 material。

## 9. 复用到其他页面的最小清单

若要在别的页面复刻这颗地球，需要搬走：

1. `EARTH_RADIUS` / `TILT` / `NIGHT_ARC_COLOR` / 两个大气色常量。
2. `earthUniforms` + `earthAtmosphereUniforms` 的声明（注意共享 Color 对象）。
3. `createEarthTexture()` / `createNightEmissiveTexture()` 两个兜底生成器。
4. `prepareEarthTexture()` 与两次 `texLoader.load()`。
5. 地球 `ShaderMaterial` 的完整 vertex/fragment 字符串（§3.2–§3.3）。
6. 大气壳 `ShaderMaterial` + `SphereGeometry(r×1.055)` + `renderOrder=2`（§4）。
7. `updateSolarTermScene()` 的太阳方向算法（若需要节气/赤纬）。
8. `animate()` 中 `earthMesh.rotation.y` 与 `updateEarthShaderUniforms()` 的每帧同步。
